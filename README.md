# StreamVerse 🦀

Rust-first, open-source video-platform project with **GitHub Pages support**.

## View the website

After enabling **Settings → Pages → Build and deployment → GitHub Actions**, the Rust exporter runs automatically and publishes the site at:

https://ankur10gupta1947-oss.github.io/octopus/

The GitHub Pages edition is a **static demo generated by Rust** containing nine mock videos, categories, watch pages, channels and a creator studio. Pages hosting does not execute the Axum server or provide authentication, upload, storage or real video playback.

## Run the Rust server locally

```sh
cargo run --bin streamverse
```

Visit http://localhost:3000.

## Generate static GitHub Pages files locally

```sh
cargo run --bin export
```

Output is written to `site/`. The repository's Pages GitHub Actions workflow runs this command automatically.

## Docker deployment of the Axum server

```sh
docker build -t streamverse .
docker run --rm -p 3000:3000 streamverse
```

## Roadmap

Database-backed accounts and creator channels, likes, comments, real uploads and playback, and a configurable 9Drive/Google Drive storage backend. No cloud storage is connected in this version. The project is **not yet a fully functional video-hosting service**.
